# Institutional logos

These white vector marks were recovered from the existing poster PDF supplied
with the local project, because its original `logos/` source directory was
not available:

- `kit-white.pdf`: Karlsruhe Institute of Technology (KIT), with the English
  institutional name.
- `fzi-white.pdf`: FZI Research Center for Information Technology.

The extraction preserves the embedded vector artwork and transparent
backgrounds. The template places both marks on the KIT green header.

Institutional logos retain their respective rights; the repository's MIT
license covers the template code, not these marks. Their inclusion does not
make this an officially endorsed institutional template. Use appropriate
institutional artwork and permissions for your publication.

For official KIT assets and current branding guidance, see the
[KIT corporate design portal](https://kit-cd.km.kit.edu/logo.php).
FZI's institutional website is [fzi.de](https://www.fzi.de/).
